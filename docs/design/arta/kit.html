arta Own Your Money

Design kit sistem arta — 28 ikon monoline, badge tier, empty state, splash, aset ikon aplikasi, dan komponen UI kecil. Semua glyph dibangun di grid 24×24 dengan stroke 1,75 dan satu keluarga bentuk, jadi bisa dipakai langsung di build Expo nanti. Sakelar Terang/Gelap di kanan atas menukar token warna seluruh halaman.
