# Integrasi UI arta — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Layar Rencana 1 memakai bahasa visual arta: token warna, 28 ikon monoline, font, mark, tab bar, hero, chip dompet, baris transaksi, keadaan kosong, dan tombol. Perilaku dan data tidak berubah.

**Architecture:**
- Token arta diperluas di `src/theme/tokens.ts`, lalu dialirkan ke CSS vars NativeWind (`ThemeProvider`) dan `tailwind.config.js`.
- Ikon dibuat dari `docs/design/arta/icons.json` oleh skrip generator menjadi data TS, lalu dirender dengan `react-native-svg` lewat satu komponen `Ikon`.
- Komponen yang sudah ada dirombak di tempat. Antarmuka props-nya hanya ditambah bila disebut di bawah.

**Tech Stack:** Expo SDK 58, React Native 0.88, NativeWind v4, `react-native-reanimated` 4 (pulau dinamis), `react-native-svg`, `expo-font` (config plugin), `@expo-google-fonts/nunito-sans`, Jest (jest-expo) + RNTL v14 (`render`/`fireEvent` async).

**Spec:** `docs/superpowers/specs/2026-11-20-arta-ui-design.md` (acuan visual: `docs/design/arta/kit.html`, `docs/design/arta/premium-trial.html`). Spec induk: `docs/spec.md`.

## Global Constraints

- Murni tampilan: semua tes perilaku yang ada tetap lolos. Tes boleh diubah hanya ketika teks/salinan yang diuji diubah oleh rencana ini, dan perubahannya disebut di task.
- Nilai token persis seperti di spec §Keputusan; jangan menebak warna lain.
- Aksen penuh (`acc`) hanya untuk mic, tombol utama, dan progres. Uang masuk/positif memakai `accInk`.
- Format uang tetap aturan domain: `Rp288.000`, `-Rp49.000`, chip `152rb` (tanpa spasi setelah "Rp", meski kit menulis "Rp 412.000").
- Ikon: viewBox `0 0 24 24`, `strokeWidth` 1.75, `strokeLinecap`/`strokeLinejoin` `round`, `fill="none"` untuk kelas `ln`; kelas `fill` = isi warna, tanpa garis.
- Teks UI berbahasa Indonesia. Label aksesibilitas yang sudah ada tidak boleh hilang.
- Jangan ubah `slug`, `scheme`, atau `android.package` di `app.json`.
- Setiap `npx expo install` mengikuti versi yang dipilih Expo SDK 58. Paket native baru (`react-native-svg`) berarti APK dev harus dibangun ulang; catat ini di `docs/uji-manual-rencana-1.md`.
- Jalankan `npx jest` dan `npx tsc --noEmit` sebelum setiap commit.

## Review Focus

1. **Nama dompet/kategori panjang** (mis. "Tabungan nikah 2027 BCA") di chip dan baris transaksi → terpotong satu baris dengan elipsis, tidak mendorong nominal keluar layar. Tes di Task 5.
2. **Kategori buatan pengguna atau huruf besar** ("Kopi", "MAKAN", `null`) → ikon kategori jatuh ke `cat-lainnya` atau cocok tanpa peduli huruf besar, tidak crash. Tes di Task 2.
3. **Mode gelap** → kartu hero putih dengan teks gelap; chip dan baris transaksi tetap terbaca (tidak ada teks putih di atas putih). Tes di Task 5.
4. **≥5 dompet harian** → chip bisa digeser horizontal, tidak terhimpit. Tes di Task 5.
5. **Font gagal dimuat atau tidak ada di jest** → app tetap merender dengan font sistem, tidak tertahan di layar kosong. Tes di Task 3.
